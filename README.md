## Scope

This collection is strictly limited to **Agent Skills** — repos following the [SKILL.md standard](https://agentskills.io) (or equivalent: MCP servers, agent workbenches) that extend AI agent capabilities for research workflows.

**Excluded**: pure research tools, simulators, frameworks, libraries, or awesome-lists. If a repo does not give an AI agent a new SKILL.md-defined capability, it does not belong here.

## Refresh Guide

### How Refresh Works

Say **"refresh"** to [WorkBuddy](https://codebuddy.ai). The assistant will:

1. **Scan**: Search GitHub, SkillsMP, and the web for new Agent Skills
2. **Fetch stars**: Query GitHub API for current star counts
3. **Compute weekly Δ**: Compare against [`stars-baseline.json`](stars-baseline.json)
4. **Update baseline**: Replace baseline with current counts
5. **Sort & rewrite**: Regenerate README and interactive page
6. **Commit & push**: `git add -A && git commit -m "Refresh: ..." && git push`

### Refresh Metadata

- **Last refreshed**: 2026-08-07
- **Repos tracked**: 41
- **Method**: Conversation-triggered (say "refresh" to WorkBuddy)
- **Scope**: Strictly Agent Skills (SKILL.md, MCP, workbenches). Pure tools excluded.

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md). PRs welcome.

### Inclusion Criteria

- Follows the [SKILL.md standard](https://agentskills.io) or equivalent (MCP server, agent workbench)
- Gives AI agents (Claude Code, Codex, Cursor, Gemini CLI, etc.) new capabilities
- Relevant to scientific research workflows
- Open source with clear documentation
- Actively maintained

### Exclusion Criteria

- Pure research tools, simulators, frameworks (e.g., robotics simulators, ML libraries)
- Awesome-lists without their own SKILL.md format
- Closed-source or proprietary skill packages
