## Scope

This collection is strictly limited to **Agent Skills** — repos following the [SKILL.md standard](https://agentskills.io) (or equivalent: MCP servers, agent workbenches) that extend AI agent capabilities for research workflows.

**Excluded**: pure research tools, simulators, frameworks, libraries, or awesome-lists. If a repo does not give an AI agent a new SKILL.md-defined capability, it does not belong here.
